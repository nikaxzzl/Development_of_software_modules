# cafe-report

## Структура проекта

```text
cafe-report
|-app # пакет, который хранит код 

| |-services # пакет, который хранит код (заказы, отчет)
| |-utils # пакет со вспомогательными функциями
|-data # пакет, который хранит входные данные
|-docs # документация проекта
|-tests # пакет, который хранит тесты для разных модулей
```
