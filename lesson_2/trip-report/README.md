# Отчёт по поездке

Программа читает данные о тратах за поездку и выводит красивый отчёт в терминал (с цветным заголовком благодаря библиотеке Rich).

## Как запустить

Все команды выполняются из корня проекта (папка `trip-report`).

1. Создать виртуальное окружение:
   ```bash
   python3 -m venv .venv
2. Активировать окружение:
   source .venv/bin/activate
3. Поставить зависимости:
   pip install -r requirements.txt
4. Запустить программу:
   python3 -m app.main
